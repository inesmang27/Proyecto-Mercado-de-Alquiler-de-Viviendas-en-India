# Proyecto-Mercado-de-Alquiler-de-Viviendas-en-India
Analizar los factores que influyen en el precio del alquiler de viviendas en India y segmentar el mercado en diferentes perfiles de clientes mediante técnicas estadísticas y análisis exploratorio de datos. Se incluye el código de R usado y una presentación sobre los diferentes análisis llevados a cabo.
